# Chirag Yadav - personal website

Plain HTML and CSS, no build step.

## Publish on GitHub Pages
1. Create a public repository named `chirag-ydv.github.io`.
2. Upload everything in this folder to the repository root (keep the folder structure).
3. In the repository, open Settings > Pages and set the source to the `main` branch, root folder.
4. The site appears at https://chirag-ydv.github.io/ within a few minutes.

## Edit
- About page: `index.html`
- Research page: `research/index.html`
- CV: replace `assets/pdf/Chirag_Yadav_CV.pdf` (keep the file name)
- Photo: add a square image at `assets/img/profile.jpg`; it shows up beside the bio automatically
- Colors and fonts: the `:root` block at the top of `assets/css/main.css`
